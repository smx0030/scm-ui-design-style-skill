# SCM UI 页面骨架与组件规则

## 1. 后台主框架（Layout）
- 左侧：深色 `Sider`，可折叠、可拖拽宽度（约 `245px` 起）。
- 导航状态细则见：`sidebar-navigation.md`（选中/展开/折叠/hover）。
- 顶部：白色 Header，左侧导航控制 + 面包屑，右侧用户与系统操作。
- 内容区：灰背景环境上叠白色内容卡片，默认内边距 `12px`。
- 高度策略：主内容常用 `calc(100vh - 126px)`。

## 2. 登录页（UserLayout）
- 整体沉浸式背景图 + 中央登录容器。
- 登录容器尺寸约 `350x350`，信息层级清晰，动效轻量（淡入 + 平移）。

## 3. 列表页标准结构
1. 查询区（`a-card` + 表单网格）
2. 操作区（主按钮在前，辅助操作在后）
3. 数据区（VXE Table，小尺寸高密度）
4. 分页区（底部固定顺序布局）

## 4. 查询区（Search Area）细则
- 推荐组件：`components/Form/SearchForm.vue`；容器默认 `margin-bottom: 12px`。
- 卡片内边距：`12px 12px`，保持紧凑信息密度。
- 表单布局：`a-row` + `a-col` 网格；常见 3 列（大屏），收起时仅首行。
- 字段类型：输入、日期、区间、级联、单选、多选等，统一占满列宽（`width: 100%`）。
- 查询动作区固定在表单尾列并右对齐：
  - 主查询按钮：`type="primary"`
  - 清空按钮：次级按钮，左间距 `6px`
  - 展开/收起：文本链接，字号 `12px`，左间距 `6px`
- 验证与提示：沿用 Ant Form rules，错误提示信息风格一致。
- 响应式原则：优先保证“首屏可查询”，复杂字段放入展开区。

## 5. 操作区（Action Area）细则
- 承载位置：优先使用 `VTable` 的 `v-slot:buttons`（主操作）和 `v-slot:tools`（辅助操作）。
- 操作顺序：主流程按钮在最左，风险/删除类随后，导入导出与配置放右侧或 tools 区。
- 间距规则：同组按钮统一 `margin-right: 6px`；块间距用 `12px`。
- 视觉优先级：
  - 主要动作：红色主按钮（`type="primary"`）
  - 次要动作：默认按钮
  - 危险动作：配合 `a-popconfirm`，避免直接触发
- 状态规则：
  - 无选中数据时，批量操作按钮必须禁用
  - 提交类动作必须有 loading 态，防重复提交
  - 不可用动作提供明确禁用态，不隐藏核心功能入口
- 与表格衔接：操作区应紧贴表格上边缘，避免产生第二视觉层级。

## 6. 抽屉/弹窗编辑页
- 常见为全宽 Drawer 或大 Modal。
- 主体滚动，底部操作栏吸底：
  - `position: absolute; bottom: 0; width: 100%`
  - `padding: 10px 16px; background: #fff; border-top: 1px solid #e9e9e9`
- 按钮顺序：关闭/取消 -> 保存 -> 提交（主操作用红色主按钮）。

## 7. 组件级规则
- 按钮：主按钮红底白字；次级按钮白底描边。
- 表格：表头浅灰背景、内容紧凑、hover 明确、空态简洁。
- 表单：标签与控件对齐，复杂表单采用固定 label 宽度 + 自适应控件宽度。
- Tabs：卡片式标签，激活态底边使用主色。
- 滚动条：统一灰阶定制，宽度约 `10px`。

## 8. 文案与视觉语气
- 偏企业系统风格：克制、清晰、工具化。
- 用色以功能表达为主，不做情绪化视觉。

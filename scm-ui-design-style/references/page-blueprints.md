# SCM UI 页面骨架与组件规则

## 1. 后台主框架（Layout）
- 左侧：深色 `Sider`，可折叠、可拖拽宽度（约 `245px` 起）。
- 顶部：白色 Header，左侧导航控制 + 面包屑，右侧用户与系统操作。
- 内容区：灰背景环境上叠白色内容卡片，默认内边距 `12px`。
- 高度策略：主内容常用 `calc(100vh - 126px)`。

## 2. 登录页（UserLayout）
- 整体沉浸式背景图 + 中央登录容器。
- 登录容器尺寸约 `350x350`，信息层级清晰，动效轻量（淡入 + 平移）。

## 3. 列表页标准结构
1. 查询区（`a-card` + 表单网格）
2. 操作区（主按钮在前，辅助操作在后）
3. 数据区（VXE Table，小尺寸高密度）
4. 分页区（底部固定顺序布局）

## 4. 抽屉/弹窗编辑页
- 常见为全宽 Drawer 或大 Modal。
- 主体滚动，底部操作栏吸底：
  - `position: absolute; bottom: 0; width: 100%`
  - `padding: 10px 16px; background: #fff; border-top: 1px solid #e9e9e9`
- 按钮顺序：关闭/取消 -> 保存 -> 提交（主操作用红色主按钮）。

## 5. 组件级规则
- 按钮：主按钮红底白字；次级按钮白底描边。
- 表格：表头浅灰背景、内容紧凑、hover 明确、空态简洁。
- 表单：标签与控件对齐，复杂表单采用固定 label 宽度 + 自适应控件宽度。
- Tabs：卡片式标签，激活态底边使用主色。
- 滚动条：统一灰阶定制，宽度约 `10px`。

## 6. 文案与视觉语气
- 偏企业系统风格：克制、清晰、工具化。
- 用色以功能表达为主，不做情绪化视觉。

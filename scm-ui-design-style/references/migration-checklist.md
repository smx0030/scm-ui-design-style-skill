# SCM UI 风格迁移清单

## A. 全局层
- [ ] 覆盖主题变量：主色、链接色、圆角。
- [ ] 设置全局基准字号与文本颜色层级。
- [ ] 统一页面背景灰、卡片白、边框灰。
- [ ] 启用统一滚动条样式。

## B. 布局层
- [ ] 落地“左侧菜单 + 顶部操作 + 内容卡片”框架。
- [ ] 内容区默认 12px 内边距。
- [ ] 页面主区域高度使用 `calc` 保持满屏可视。

## C. 页面层
- [ ] 列表页遵循“查询 -> 操作 -> 表格 -> 分页”。
- [ ] 编辑页使用底部吸附操作栏。
- [ ] 关键按钮间距统一 `6px`。

## D. 组件层
- [ ] 按钮主次关系符合红主色体系。
- [ ] 表头背景、链接色、禁用态与原风格一致。
- [ ] Tabs 激活态、表单间距与标签对齐一致。

## E. 验收标准
- [ ] 首屏视觉可一眼识别为 SCM UI 同体系。
- [ ] 常见页面（列表/表单/抽屉）在 80% 场景无需额外样式补丁。
- [ ] 新旧项目并排对比时，配色、密度、层次无明显跳变。

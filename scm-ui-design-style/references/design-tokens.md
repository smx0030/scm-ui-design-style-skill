# SCM UI 设计 Token

## 1. 色彩系统
- 主色（品牌/强调）：`#f5222d`
- 链接/交互蓝：`#1890ff`
- 页面背景灰：`#f0f2f5`
- 区块浅灰背景：`#fafafa`
- 白底卡片：`#ffffff`
- 主文本：`rgba(0, 0, 0, 0.85)`
- 次级文本：`rgba(0, 0, 0, 0.65)`
- 弱化文本：`rgba(0, 0, 0, 0.45)` / `rgba(0, 0, 0, 0.25)`
- 分隔线/边框：`#e8e8e8`

## 2. 字体与字号
- 主体默认：`12px`
- 常用正文/按钮：`14px`
- 强调信息与图标常见：`16px`
- 页面标题或局部强调：`18px` / `20px`
- 登录页标题可提升至 `25px+`
- 字重：正文常规，表头与关键标题 `600~900`

## 3. 圆角与边框
- 基础圆角：`2px`（主题级）
- 输入框常见：`4px`
- 卡片局部可用：`6px`
- 边框主用：`1px solid #e8e8e8`

## 4. 阴影与层级
- 主内容卡片阴影：`0 2px 12px rgba(0,0,0,0.1)`
- 全屏弹层弱阴影或无阴影，强调内容非装饰。

## 5. 间距节奏（高频）
- 微间距：`6px`
- 小间距：`8px`
- 基础间距：`12px`
- 中间距：`16px`
- 大间距：`24px`
- 常见按钮间距：右侧 `6px`

## 6. 动效
- 基础过渡时长：`0.3s` / `0.5s`
- 页面切换动效：淡入淡出 + 轻位移（X 轴）
- 避免复杂动效，保持“快、稳、弱存在感”。

## 7. 主题覆盖点（Ant Design Vue）
- `primary-color`: `#f5222d`
- `link-color`: `#f5222d`
- `border-radius-base`: `2px`
- `alert-info-*`: 红系衍生（边框/背景/图标）
